# 資産管理アプリ

シンプルなフロントエンドのみの資産管理アプリです。ブラウザの `localStorage` にデータを保存します。

## 機能

- 資産（資産名 / カテゴリ / 金額 / メモ）の追加
- 資産一覧表示
- 総資産の自動計算
- カテゴリごとの集計表示
- 個別削除 / 全削除
- ページ再読み込み後もデータ保持（localStorage）

## 使い方

1. このリポジトリ直下で簡易サーバーを起動:

   ```bash
   python3 -m http.server 8000
   ```

2. ブラウザで以下を開く:

   - <http://localhost:8000>

## ファイル構成

- `index.html`: 画面構造
- `style.css`: スタイル
- `app.js`: 資産データ処理と描画
