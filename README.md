# 資産管理アプリ

シンプルなフロントエンドのみの資産管理アプリです。ブラウザ上で資産を登録・削除し、カテゴリ別の合計を確認できます。

## 機能

- 資産名 / カテゴリ / 金額を入力して追加
- 資産一覧表示と削除
- 総資産、現金、預金、投資の合計を自動計算
- `localStorage` を使った永続化

## 使い方

1. `index.html` をブラウザで開きます。
2. フォームに資産情報を入力し「追加」を押します。
3. 一覧から不要な行は「削除」で取り除けます。

## ファイル構成

- `index.html`: 画面構造
- `styles.css`: UI スタイル
- `app.js`: 画面ロジックと保存処理
