# 資産管理アプリ

ブラウザで動作するシンプルな資産管理アプリです。以下の機能があります。

- 資産（名前 / カテゴリ / 金額）の追加
- 資産の編集・削除
- 総資産と登録件数の自動集計
- `localStorage` によるデータ永続化

## 使い方

1. `index.html` をブラウザで開きます。
2. フォームに資産情報を入力して「追加」を押します。
3. 一覧の「編集」「削除」でデータを更新できます。
4. 「全件削除」で登録データを初期化できます。

## 開発時の起動例

```bash
python3 -m http.server 8000
```

その後、`http://localhost:8000` にアクセスしてください。
